# 📚 CRUD de Estudiantes - Spring Boot  

Este es un **CRUD** de estudiantes desarrollado con **Spring Boot**, **Thymeleaf**, **JPA** y **MySQL**.  

## Cómo ejecutar el proyecto  

###  1️⃣ Accede a la aplicación en:
🔗 [http://localhost:8080/student](http://localhost:8080/student)

###  2️⃣ Ejecutar pruebas unitarias  

Ejecutar todas las pruebas a la vez:
```bash
mvn test
```

### 3️⃣ Ejecutar una prueba unitaria específica
```bash
mvn -Dtest=StudentControllerTest test
```
